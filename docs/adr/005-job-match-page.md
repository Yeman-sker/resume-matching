# ADR-005: 岗位匹配查询页面

## 状态

已批准（Accepted）

## 背景

参考 Streamlit 应用的**岗位匹配求职者**页面功能：

1. **岗位选择**：下拉框选择岗位（格式 `JOB_001 - Python开发工程师`）
2. **岗位详情**：选中后展示岗位名称、部门、城市、经验要求、要求技能
3. **Top-N 控制**：滑块控制显示 3-20 名候选人
4. **匹配卡片列表**：每张卡片包含：
   - 排名 + 候选人姓名 + 岗位名称
   - 综合分指标
   - 6 个评分进度条（综合分、语义分、技能分、经验分、学历分、城市分）
   - 推荐理由文本
   - 共同技能和缺失技能展示

PRD 中模块 C 的要求是**左右分栏布局**（左侧岗位列表 30%，右侧匹配结果 70%），比 Streamlit 的下拉框选择更直观。

## 决策

采用 PRD 指定的**左右分栏布局**，左侧岗位列表支持筛选和搜索，右侧展示匹配的候选人卡片列表。

### 5.2 组件设计

#### JobListPanel（左侧岗位列表）

```tsx
interface JobListPanelProps {
  jobs: Job[]
  selectedJobId: string | null
  onSelectJob: (jobId: string) => void
  departments: string[]
}
```

**功能**：
- 搜索框：按岗位名称实时过滤
- 部门下拉筛选（多选）
- 岗位列表：显示 job_id、岗位名称、部门、城市
- 选中项高亮
- 支持 URL 参数同步（`/jobs?jobId=JOB_001`）

#### JobDetailHeader（匹配结果区顶部）

```tsx
interface JobDetailHeaderProps {
  job: Job
  matchCount: number
}
```

**功能**：
- 显示选中岗位基本信息（名称、部门、城市、经验要求、薪资范围）
- 显示匹配候选人总数

#### MatchCard（匹配结果卡片）

```tsx
interface MatchCardProps {
  rank: number
  match: Match
  mode: 'job' | 'resume'
  onViewDetail: (resumeId: string, jobId: string) => void
}
```

**功能**：
- 排名 + 姓名 + 综合分大字显示
- 各维度分数进度条（语义分、技能分、学历分、经验分、城市分）
- 共同技能标签（绿色）+ 缺失技能标签（红色）
- 推荐理由文本（默认折叠，点击展开）
- 「查看详情」按钮跳转到 MatchDetailPage

#### ScoreBar（分数进度条）

```tsx
interface ScoreBarProps {
  label: string
  value: number       // 0-100
  maxScore?: number   // 默认 100
  colorClass?: string // Tailwind 颜色类
}
```

**功能**：
- 标签 + 数值 + 进度条
- 分数颜色：< 60 红色，60-80 黄色，> 80 绿色
- 进度条宽度 = value / 100

### 5.3 数据流

```
页面加载
  → fetchJobs() 获取所有岗位列表
  → 用户选择岗位
  → fetchJobMatches(selectedJobId, limit=50)
  → 渲染匹配卡片列表
  → 用户切换岗位
  → 重新 fetchJobMatches
```

### 5.4 与 Streamlit 参考的差异

| 维度 | Streamlit 版本 | React 版本 |
|------|--------------|-----------|
| 岗位选择方式 | 下拉框 selectbox | 左侧列表点击选择 |
| 布局 | 单栏垂直 | 左右分栏（30/70） |
| 筛选 | 侧边栏全局筛选 | 列表内搜索 + 部门筛选 |
| Top-N | 滑块 3-20 | 下拉框 10/20/50 |
| 卡片交互 | 无详情跳转 | 「查看详情」跳转 |
| 进度条 | st.progress | 自定义 ScoreBar |
| 路由 | 无 | URL 参数 `/jobs?jobId=JOB_001` |

### 5.5 API 调用

1. **页面加载时**：`GET /api/jobs` → 存入 Zustand store
2. **选择岗位时**：`GET /api/jobs/{jobId}/matches?limit=50` → 渲染匹配列表
3. **每 60 秒轮询**：`GET /api/jobs` 刷新岗位列表

### 5.6 空状态和加载态

- **加载中**：骨架屏（Skeleton）
- **无数据**：EmptyState 组件提示"暂无岗位数据，请确保中游数据处理服务正在运行"
- **无匹配结果**："当前岗位暂无匹配的候选人"
