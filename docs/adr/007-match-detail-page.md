# ADR-007: 匹配详情页面

## 状态

已批准（Accepted）

## 背景

参考 Streamlit 应用中的 `render_match_card` 函数，每张匹配卡片已包含：

1. **排名 + 姓名/岗位名 + 综合分**
2. **各维度评分进度条**：综合分、语义分、技能分、经验分、学历分、城市分
3. **推荐理由文本**
4. **共同技能 + 缺失技能**

但 Streamlit 版本**没有独立的详情页面**，所有信息都在卡片内展示。

PRD 模块 E 要求一个**独立的匹配详情页**，展示更详细的信息：

1. **左右基本信息对比**：左侧简历信息 / 右侧岗位信息
2. **分数详情区**：各维度分数以可视化方式展示（进度条 + 权重标注）
3. **推荐理由区**：详细的文字说明

## 决策

创建独立的匹配详情页面，从岗位匹配/简历推荐页面的「查看详情」按钮跳转进入。

### 7.2 组件设计

#### MatchDetailPage（主页面）

```tsx
// 路由: /match/:resumeId/:jobId
// 从 URL 参数获取 resumeId 和 jobId
// 调用 GET /api/matches/{resumeId}/{jobId} 获取数据
```

#### InfoCard（信息卡片）

```tsx
interface InfoCardProps {
  title: '简历信息' | '岗位信息'
  data: Record<string, string | number>
  skills?: string[]
  skillType?: 'standard' | 'required' | 'preferred'
}
```

**功能**：
- 以键值对形式展示基本信息
- 技能标签以彩色标签组形式展示
- 简历信息用蓝色调，岗位信息用绿色调

#### ScoreBreakdown（分数详情面板）

```tsx
interface ScoreBreakdownProps {
  totalScore: number
  semanticScore: number
  tfidfScore: number
  word2vecScore: number
  ruleScore: number
  skillScore: number
  educationScore: number
  experienceScore: number
  cityScore: number
  salaryScore: number
  certificateScore: number
}
```

**功能**：
- **综合分**大字显示在右上角
- **语义分**区块：进度条 + 权重标注(60%)，子项 TF-IDF 分和 Word2Vec 分缩进显示
- **规则分**区块：进度条 + 权重标注(40%)，子项各维度分缩进显示（含权重百分比）
- 分数颜色：< 60 红色, 60-80 黄色, > 80 绿色

#### SkillMatchSection（技能匹配区）

```tsx
interface SkillMatchSectionProps {
  matchedSkills: string[]
  missingSkills: string[]
}
```

**功能**：
- 共同技能：绿色标签组
- 缺失技能：红色标签组

#### ReasonSection（推荐理由区）

```tsx
interface ReasonSectionProps {
  reason: string
}
```

**功能**：
- 推荐理由文本（从匹配结果的 `reason` 字段）
- 编号列表格式展示

### 7.3 数据流

```
页面加载
  → 从 URL 参数获取 resumeId 和 jobId
  → fetchMatchDetail(resumeId, jobId)
  → 渲染左右信息卡片 + 分数详情 + 技能匹配 + 推荐理由
```

### 7.4 路由设计

```
/match/RES_001/JOB_001
```

**返回按钮**：
- 从岗位匹配页面进入 → 返回 `/jobs?jobId=JOB_001`
- 从简历推荐页面进入 → 返回 `/resumes?resumeId=RES_001`

通过 URL query 参数 `from` 记录来源页面：

```
/match/RES_001/JOB_001?from=jobs&fromId=JOB_001
/match/RES_001/JOB_001?from=resumes&fromId=RES_001
```

### 7.5 API 调用

- **页面加载时**：`GET /api/matches/{resumeId}/{jobId}`
- 无轮询（详情页数据不需要实时更新）

### 7.7 与 Streamlit 参考的差异

| 维度 | Streamlit 版本 | React 版本 |
|------|--------------|-----------|
| 展示形式 | 嵌入卡片列表中 | 独立详情页 |
| 信息对比 | 无 | 左右简历/岗位对比 |
| 分数展示 | 6 个独立进度条 | 树状分组（语义/规则） |
| 权重标注 | 无 | 每个维度标注权重百分比 |
| 推荐理由 | 简短文本 | 编号列表 + 详细说明 |
