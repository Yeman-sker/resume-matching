# ADR-008: 数据生成器控制页面

## 状态

已批准（Accepted）

## 背景

参考 Streamlit 应用**没有**数据生成器控制功能（Streamlit 版本假设数据已预先准备好）。PRD 模块 B 要求在 Web 界面上控制数据生成器的启停和配置。

当前数据生成器（端口 8000）已提供以下 API：

- `POST /control` — 启停（`{"action": "start"}` 或 `{"action": "stop"}`）
- `GET /status` — 查询状态

PRD 5.1.2 节要求的控制面板功能：

1. **启动按钮**：调用 `POST /api/generator/start`
2. **停止按钮**：调用 `POST /api/generator/stop`
3. **配置面板**：
   - 简历生成间隔（秒）
   - 岗位生成间隔（秒）
   - 刷新间隔（秒）
4. **状态显示**：
   - 运行状态
   - 已生成简历数 / 岗位数
   - 生成速率
   - 最近生成的数据预览

## 决策

创建数据生成器控制页面，通过后端代理转发请求到数据生成器服务（端口 8000）。

### 8.2 组件设计

#### GeneratorStatusCard（运行状态卡片）

```tsx
interface GeneratorStatus {
  running: boolean
  total_resumes: number
  total_jobs: number
  buffer_size: { resumes: number; jobs: number }
  last_flush_time: string
  generation_rate?: { resumes_per_minute: number; jobs_per_minute: number }
}
```

**功能**：
- 运行状态指示灯（绿色 = 运行中，灰色 = 已停止）
- 4 个统计指标卡片（已生成简历、已生成岗位、简历速率、岗位速率）
- 最后刷新时间

#### GeneratorControlPanel（控制面板）

```tsx
interface GeneratorConfig {
  resume_interval_seconds: number
  job_interval_seconds: number
  flush_interval_seconds: number
}
```

**功能**：
- 启动按钮（绿色，运行中时禁用）
- 停止按钮（红色，停止时禁用）
- 三个配置输入框（简历间隔、岗位间隔、刷新间隔）
- 应用配置按钮

#### DataPreview（数据预览表格）

```tsx
// 最近生成的简历和岗位
// 使用 shadcn/ui Table 组件展示
```

### 8.3 数据流

```
页面加载
  → GET /api/generator/status（通过后端代理）
  → 渲染运行状态卡片和控制面板

定时轮询（每 5 秒）
  → GET /api/generator/status
  → 更新运行状态

用户操作
  → 点击启动 → POST /api/generator/start
  → 点击停止 → POST /api/generator/stop
  → 修改配置 → 应用配置 → POST /api/generator/start（带配置参数）
```

### 8.4 后端代理接口

#### 启动生成器

```
POST /api/generator/start
```

**请求体**（可选）：
```json
{
  "resume_interval_seconds": 30,
  "job_interval_seconds": 60,
  "flush_interval_seconds": 60
}
```

**后端逻辑**：转发到 `http://localhost:8000/control`，请求体 `{"action": "start", ...config}`

#### 停止生成器

```
POST /api/generator/stop
```

**后端逻辑**：转发到 `http://localhost:8000/control`，请求体 `{"action": "stop"}`

#### 查询状态

```
GET /api/generator/status
```

**后端逻辑**：转发到 `http://localhost:8000/status`

**注意**：需确认数据生成器的实际 API 路径。根据 `data_generator/data_generator.py`，现有 API 为：
- `POST /control` — `{"action": "start"}` 或 `{"action": "stop"}`
- `GET /status` — 返回运行状态

后端代理将 `/api/generator/*` 映射到 `http://localhost:8000/*`。

### 8.5 与 Streamlit 参考的差异

| 维度 | Streamlit 版本 | React 版本 |
|------|--------------|-----------|
| 数据生成器控制 | 无 | 完整控制面板 |
| 启停按钮 | 无 | 启动/停止按钮 |
| 配置参数 | 无 | 可配置间隔参数 |
| 状态显示 | 无 | 实时状态卡片 |
| 数据预览 | 仅全量表格 | 最近生成数据预览 |

### 8.6 错误处理

- 数据生成器未启动时：显示"生成器服务未连接"，启动按钮置灰
- 启动失败时：显示错误提示 Toast
- 操作确认：停止生成器前弹出确认对话框
