# ADR-006: 简历推荐查询页面

## 状态

已批准（Accepted）

## 背景

参考 Streamlit 应用的**简历推荐岗位**页面功能：

1. **简历选择**：下拉框选择简历（格式 `RES_001 - 张三`）
2. **简历详情**：选中后展示姓名、学历、城市、经验年限、技能列表
3. **Top-N 控制**：滑块控制显示 3-20 个推荐岗位
4. **推荐卡片列表**：与岗位匹配页面结构一致（综合分、各维度进度条、推荐理由、技能标签）

PRD 模块 D 要求与模块 C 左右调换（左侧简历列表 30%，右侧推荐岗位 70%）。

## 决策

简历推荐查询页面与岗位匹配查询页面采用对称设计，组件复用度高。

### 6.2 复用组件

以下组件可直接复用岗位匹配页面的组件：

| 组件 | 岗位匹配页面 | 简历推荐页面 | 复用方式 |
|------|-----------|-----------|---------|
| `MatchCard` | 候选人卡片 | 推荐岗位卡片 | 通过 `mode` prop 区分 |
| `ScoreBar` | 分数进度条 | 同左 | 完全复用 |
| `SkillTags` | 共同/缺失技能 | 同左 | 完全复用 |
| `EmptyState` | 空状态 | 同左 | 完全复用 |
| `LoadingSpinner` | 加载状态 | 同左 | 完全复用 |

### 6.3 独有组件

#### ResumeListPanel（左侧简历列表）

```tsx
interface ResumeListPanelProps {
  resumes: Resume[]
  selectedResumeId: string | null
  onSelectResume: (resumeId: string) => void
}
```

**功能**：
- 搜索框：按姓名实时过滤
- 简历列表：显示 resume_id、姓名、学历、经验年限、技能标签
- 选中项高亮
- URL 参数同步（`/resumes?resumeId=RES_001`）

**与 JobListPanel 的差异**：
- 无部门筛选（简历无部门属性）
- 列表项显示学历 + 经验而非部门 + 城市
- 技能标签以小标签形式展示

#### ResumeDetailHeader（推荐结果区顶部）

```tsx
interface ResumeDetailHeaderProps {
  resume: Resume
  matchCount: number
}
```

**功能**：
- 显示选中简历基本信息（姓名、学历、经验、技能、期望薪资、城市）
- 显示推荐岗位总数

### 6.4 数据流

```
页面加载
  → fetchResumes() 获取所有简历列表
  → 用户选择简历
  → fetchResumeRecommendations(selectedResumeId, limit=50)
  → 渲染推荐岗位卡片列表
  → 用户切换简历
  → 重新 fetchResumeRecommendations
```

### 6.5 与 Streamlit 参考的差异

| 维度 | Streamlit 版本 | React 版本 |
|------|--------------|-----------|
| 简历选择方式 | 下拉框 selectbox | 左侧列表点击选择 |
| 布局 | 单栏垂直 | 左右分栏（30/70） |
| 搜索 | 无 | 按姓名实时搜索 |
| Top-N | 滑块 3-20 | 下拉框 10/20/50 |
| 卡片交互 | 无详情跳转 | 「查看详情」跳转 |
| 路由 | 无 | URL 参数 `/resumes?resumeId=RES_001` |

### 6.6 API 调用

1. **页面加载时**：`GET /api/resumes` → 存入 Zustand store
2. **选择简历时**：`GET /api/resumes/{resumeId}/recommendations?limit=50`
3. **每 60 秒轮询**：`GET /api/resumes` 刷新简历列表
