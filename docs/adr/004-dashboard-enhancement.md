# ADR-004: 系统监控面板增强

## 状态

已批准（Accepted）

## 背景

参考 Streamlit 应用的**项目概览**页面提供以下功能：

1. **统计指标卡片**：简历数量、岗位数量、匹配结果数、最高综合分、平均综合分
2. **分数分布柱状图**：展示各维度平均分（total_score、semantic_score、skill_score、experience_score）
3. **侧边栏筛选**：部门筛选、最低综合分筛选

当前 React Dashboard 页面仅有：

- 3 张统计卡片（简历总数、岗位总数、匹配总数）
- 系统状态显示（数据生成器、Streaming、批处理）
- 最后更新时间

### 差距分析

| 功能 | Streamlit 版本 | 当前 React 版本 | 差距 |
|------|---------------|----------------|------|
| 统计指标卡片 | 5 个（含最高分、平均分） | 3 个（仅数量） | 缺少最高分、平均分 |
| 分数分布图 | 有 | 无 | 需新增 |
| 系统状态 | 无 | 有 | React 版本更好 |
| 部门筛选 | 有 | 无 | 全局筛选移至各业务页面 |
| 数据量实时更新 | CSV 静态读取 | WebSocket 实时 | React 版本更好 |

## 决策

增强 Dashboard 页面，添加统计图表和更丰富的指标，同时保留 WebSocket 实时推送优势。

### 4.2 数据来源

| 数据 | 来源 | 更新方式 |
|------|------|---------|
| 简历数、岗位数、匹配数 | WebSocket `/ws`（已有） | 实时（每 2 秒） |
| 最高匹配分、平均匹配分 | `GET /api/stats`（新增） | 页面加载时请求 + 每 60 秒轮询 |
| 各维度平均分 | `GET /api/stats`（新增） | 同上 |
| 系统运行状态 | WebSocket `/ws`（已有） | 实时（每 2 秒） |

### 4.4 查看 Streamlit 参考对应关系

| Streamlit 功能 | React 实现 | 说明 |
|---------------|-----------|------|
| 5 个 `st.metric` 指标 | `DataStatsCards` 组件 | 布局从 5 列改为 5 列卡片 |
| `st.bar_chart` 分数分布 | `MetricsChart` (recharts) | 柱状图风格略有不同 |
| 侧边栏筛选 | 移至各业务页面 | Dashboard 不做全局筛选 |
| 系统状态 | `SystemStatusCard` | Streamlit 无此功能，React 版本独有 |

## 影响

### 优点

1. **一目了然**：首页即展示核心指标和分数分布
2. **实时性**：WebSocket 推送数量指标，统计分数据 60 秒轮询刷新
3. **快捷导航**：首页提供快捷入口跳转到业务页面

### 缺点

1. 需要新增 `/api/stats` 接口
2. 需要安装 `recharts` 依赖
